Что проверяется на каждом уровне

Контракт API

Rest Assured проверяет статус, тело и структуру ответа: POST /habits/{id}/checkins, GET /habits/{id}/stats.

Данные в PostgreSQL

Прямые SQL-запросы подтверждают, что запись действительно легла в таблицу, уникальность даты соблюдена, а каскад удаления не оставил «висячих» строк.

Событие в Kafka

После чек-ина в топик habit-events уходит HABIT_CHECKIN_CREATED с habitId, userId и датой.
